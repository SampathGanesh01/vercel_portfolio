## Running locally

**1. Clone the repository**
```
git clone https://github.com/SampathGanesh01/vercel_portfolio.git
```

**2. Install dependencies**
```
npm install
```

**3. Run dev server**
```
npm run dev
```

## Stack

- **Framework**: Next.js 16 (App Router)
- **Content**: MDX with gray-matter
- **UI**: Once UI design system
- **Deployment**: Vercel

## Structure

```
src/
├── app/
│   ├── work/projects/     # Project MDX files
│   └── blog/posts/        # Blog post MDX files
├── resources/
│   ├── content.tsx        # All personal content & copy
│   └── once-ui.config.ts  # Theme, routes & UI config
└── components/            # React components
```
